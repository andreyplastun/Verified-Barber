# ТЗ: СИСТЕМА ВЕСОВ, ДОВЕРИЯ И СТАБИЛИЗАЦИИ РЕЙТИНГА

## 0. Термины
- окно недели = последние 7 суток (rolling)
- окно месяца = последние 30 суток (rolling)
- новый клиент = номер, который ранее не оставлял отзыв этому мастеру

---

## 1. Статус рейтинга
- confirmed = true, если total_reviews >= 100
- иначе статус = forming

---

## 2. Минимальная активность
- completed_visits_7d >= 5
- если <5 → activity_weight = 0.7
- иначе → 1.0

---

## 3. Новые клиенты (7 дней)
new_clients_7d = уникальные новые номера за 7 дней

- >= 3 → new_weight = 1.0
- = 2 → new_weight = 0.85
- <= 1 → new_weight = 0.6

---

## 4. Геофенсинг
- радиус основной: 150 м
- допуск: 500 м

- <=150 м → geo_weight = 1.0
- 150–500 м → 0.6
- >500 м → 0.2
- нет гео → 0.5

---

## 5. Повторные отзывы
- 1 номер = 1 отзыв / 60 дней
- иначе → repeat_weight = 0

---

## 6. Скорость отзывов
- <=3 отзывов/час → speed_weight = 1.0
- 4–6 → 0.5
- >6 → 0.2

Дополнительно:
- >=3 отзывов за 10 минут → burst_weight = 0.5

---

## 7. Распределение (7 дней)
- max_day_share <= 0.4 → distribution_weight = 1.0
- 0.4–0.7 → 0.7
- >0.7 → 0.4

---

## 8. Ранние отзывы
- 1–50 → early_weight = 0.65
- 51–100 → 0.85
- 101+ → 1.0

---

## 9. Тексты отзывов

Нормализация:
- lower case, без пробелов

Похожие, если:
- совпадение >= 80%

Правила:
- если совпадает с >=2 отзывами за 7 дней → text_weight = 0.5
- без текста → 0.8
- иначе → 1.0

---

## 10. Всплеск новых клиентов

Активируется если:
days_since_first_review >= 30
AND total_reviews >= 50

avg_new_clients_7d = среднее за последние 30 дней

Всплеск:
- new_clients_7d >= max(8, 2 * avg_new_clients_7d) → new_surge_weight = 0.5

Экстремальный:
- new_clients_7d >= 12 AND >= 3 * avg → new_surge_weight = 0.3

Если одновременно:
- geo_share >= 0.7
- distribution_weight >= 0.8

→ new_surge_weight = 0.8

---

## 11. Итоговый вес отзыва

final_weight =
  activity_weight *
  new_weight *
  geo_weight *
  repeat_weight *
  speed_weight *
  burst_weight *
  distribution_weight *
  early_weight *
  text_weight *
  new_surge_weight

если любой множитель = 0 → отзыв не учитывается

---

## 12. Сглаживание рейтинга

display_rating = 0.8 * previous_display_rating + 0.2 * current_calculated_rating

---

## 13. Условия применения штрафов
- штраф применяется только если условие держится >= 24 часов

---

## 14. Задержка отображения
- после активации штрафа → применяется через 12 часов

---

## 15. Ограничение изменения рейтинга
- max_change_per_day = 0.2
- максимум ±0.2 за 24 часа

---

## 16. Разделение рейтингов
- internal_rating — полный расчёт
- display_rating — только через сглаживание и лимиты

---

## ИТОГ

Рейтинг считается сильным только если:
- >=100 отзывов
- >=3 новых клиента каждую неделю
- есть гео
- нет всплесков
- равномерное распределение

---

ФИНАЛ:
накрутка не запрещена, но не даёт веса, не масштабируется и не влияет на рейтинг
