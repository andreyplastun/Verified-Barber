АНТИФРОД ОТЗЫВОВ (МЯГКИЙ, НЕБЛОКИРУЮЩИЙ)

Цель

Снизить влияние накрученных и нерелевантных отзывов, не блокируя пользователей и не скрывая отзывы, сохраняя доверие к системе рейтингов.

⸻

1️⃣ Общий принцип
	•	Все отзывы публикуются
	•	Ни один отзыв не удаляется
	•	Часть отзывов не участвует в формировании статуса
«Сформированный рейтинг»

❗ Пользователь не обвиняется и не блокируется

⸻

2️⃣ Когда отзыв считается ограниченным для рейтинга

Отзыв помечается как ограниченный для расчёта статуса “Сформированный рейтинг”, если выполняется хотя бы одно из условий:

2.1 Частота
	•	Одному специалисту оставлено 3 или более отзывов за 24 часа

⸻

2.2 Возраст аккаунта
	•	Возраст аккаунта пользователя менее 7 дней

⸻

2.3 Текст отзыва (одинаковые или похожие формулировки)

Отзыв считается подозрительным по тексту, если:
	•	текст полностью совпадает с другими отзывами этому специалисту
ИЛИ
	•	текст имеет высокую степень схожести с другими отзывами (после нормализации)

Нормализация текста включает:
	•	приведение к нижнему регистру
	•	удаление знаков препинания
	•	удаление стоп-слов (например: «очень», «просто», «супер», «отлично», «мастер»)
	•	схлопывание пробелов


2.3.1 Нормализация текста (обязательный шаг)

Перед сравнением каждый текст отзыва приводится к нормализованному виду:
	1.	Привести весь текст к нижнему регистру
	2.	Удалить знаки препинания
	3.	Удалить цифры
	4.	Удалить стоп-слова (фиксированный список):

очень
просто
супер
отличный
отличная
понравилось
понравился
мастер
рекомендую
советую

5.	Заменить несколько пробелов на один
	6.	Обрезать текст до максимум 200 символов

Результат → normalized_text

⸻

2.3.2 Полное совпадение текста (дубликаты)

Если:
	•	normalized_text полностью совпадает
	•	с другим normalized_text
	•	у другого пользователя
	•	для того же специалиста
	•	в период 72 часов

➡️ Отзыв помечается как ограниченный для рейтинга

⸻

2.3.3 Частичное совпадение (похожий текст)

Если:
	•	длина normalized_text ≥ 40 символов
	•	коэффициент схожести текста ≥ 80%
(допустим любой простой алгоритм: Levenshtein / Jaccard / cosine similarity)
	•	сравнение проводится только с отзывами:
	•	тому же специалисту
	•	за последние 7 дней

➡️ Отзыв помечается как ограниченный для рейтинга

⸻

2.3.4 Что НЕ нужно делать
	•	❌ не использовать ML / embeddings
	•	❌ не анализировать семантику
	•	❌ не сравнивать отзывы разных специалистов
	•	❌ не учитывать короткие тексты (< 40 символов) для similarity

⸻

2.3.5 Хранение (рекомендовано)

Для каждого отзыва хранить:
	•	normalized_text
	•	is_rating_limited = true / false
	•	rating_limit_reason (internal, не показывать пользователю):
	•	duplicate_text
	•	similar_text
	•	new_account
	•	frequency
	•	expired

⸻

2.3.6 Поведение UI (напоминание)
	•	❌ пользователю не показывать причину
	•	✔️ отзыв публикуется
	•	❌ отзыв не участвует в статусе «Сформированный рейтинг»

⸻

2.4 Срок давности
	•	Попытка оставить отзыв позже 7 дней после визита

⸻

3️⃣ Поведение системы для таких отзывов

Если отзыв подпадает под любое из условий выше:
	•	✔️ отзыв публикуется
	•	✔️ отзыв виден всем пользователям
	•	✔️ оценка (звёзды) отображается
	•	❌ отзыв не учитывается при определении статуса
«Сформированный рейтинг»

(Если реализована весовая модель — допускается пониженный вес,
но по умолчанию — просто исключение из статуса)

⸻

4️⃣ Информирование пользователя (только для аккаунтов < 7 дней)

Когда показывать
	•	Пользователь оставляет отзыв
	•	Возраст аккаунта < 7 дней

Поведение
	•	Отзыв разрешён
	•	Показывается одно информационное всплывающее окно
	•	Без блокировки действия

⸻

Текст всплывающего окна (ФИНАЛЬНЫЙ, БЕЗ ПРАВОК)

Заголовок:
Почему этот отзыв может не влиять на рейтинг?

Текст:
Мы показываем все отзывы.
Но для расчёта рейтинга учитываются отзывы от пользователей, которые уже немного знакомы с сервисом.

Ваш отзыв будет виден другим пользователям и поможет мастеру,
а в рейтинг он начнёт влиять чуть позже.

Кнопка:
Понятно

⸻

5️⃣ Запрещено (строго)
	•	❌ использовать слова:
подозрительный, накрутка, антифрод, недоверие
	•	❌ блокировать отправку отзыва
	•	❌ скрывать отзывы
	•	❌ показывать пользователю внутренние причины ограничения

⸻

6️⃣ Условия приёмки

Задача считается выполненной, если:
	•	все отзывы публикуются
	•	ограничения влияют только на статус «Сформированный рейтинг»
	•	сообщение для новых аккаунтов показывается корректно
	•	UX спокойный, без повторяющихся окон
	•	логика работает одинаково для всех специалистов
