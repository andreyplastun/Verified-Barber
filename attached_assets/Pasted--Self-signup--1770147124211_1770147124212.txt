ТЗ: Self-signup специалистов + права в админке

Цель

Убрать ручное добавление специалистов через агента/SQL.
Дать:
	1.	самостоятельную регистрацию специалистов
	2.	мне — возможность добавлять/редактировать специалистов в админке

Это инфраструктурный шаг для перехода к рынку доверия.

⸻

Часть 1. Self-signup специалистов (обязательно)

1. Entry point

Добавить кнопку / ссылку:

«Добавить себя как специалиста»

	•	Доступна без авторизации
	•	Ведёт на /specialist-signup

⸻

2. Страница /specialist-signup (1 экран)

Поля формы (минимум, ничего лишнего):
	•	Имя и фамилия (text)
	•	Категория (select, из существующих)
	•	Подкатегория (опционально, если есть)
	•	Город (select, по умолчанию Алматы)
	•	Место приёма (text, свободный ввод)
	•	Телефон (обязательный, уникальный)
	•	Чекбокс:
☐ Я понимаю, что клиенты смогут оставлять отзывы

Кнопка:

Отправить заявку

⸻

3. Логика после отправки

При submit:
	•	Создаётся запись в specialists
	•	Поля:
	•	status = 'pending'
	•	rating_status = 'формируется'
	•	is_active = false
	•	Специалист НЕ отображается в общем списке

После успешной отправки:

«Заявка принята. Профиль станет доступен после первых отзывов.»

⸻

4. Активация специалиста

Специалист становится видимым, когда:
	•	✅ получил N отзывов (например 3)
ИЛИ
	•	✅ активирован вручную из админки

⸻

Часть 2. Права и админка (обязательно)

5. Роли

Добавить роль:
	•	admin

Назначить её моему аккаунту.

⸻

6. Админка: управление специалистами

В админке добавить возможность:

Я могу:
	•	➕ Добавлять специалиста вручную
	•	✏️ Редактировать:
	•	имя
	•	категорию / подкатегорию
	•	город
	•	место приёма
	•	телефон
	•	статус (pending / active)
	•	✅ Активировать / деактивировать специалиста
	•	👀 Видеть список pending специалистов

❌ Клиенты и специалисты не имеют этих прав.

⸻

Часть 3. Безопасность и ограничения
	•	Self-signup только для специалистов
	•	Клиенты не видят:
	•	страницу signup
	•	статус pending
	•	Никакого публичного создания специалистов через API

⸻

Acceptance criteria (что считаем готовым)
	•	Любой специалист может сам подать заявку
	•	Заявка не появляется в каталоге автоматически
	•	Я могу:
	•	добавить специалиста сам
	•	активировать/деактивировать
	•	Добавление через агента / SQL больше не требуется

⸻

Важно (не делать)

❌ Не делать:
	•	общий signup «для всех»
	•	регистрацию клиентов
	•	сложные онбординги
	•	подтверждения по email / sms
