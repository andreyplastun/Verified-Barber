ЦЕЛЬ

Повысить конверсию завершённый визит → отзыв за счёт входа по magic link без логина/пароля, через WhatsApp.

⸻

1️⃣ Когда и как создаётся magic link

Триггер

Magic link создаётся после оплаты визита (НЕ после закрытия записи).

Для кого

Для конкретного:
	•	клиента
	•	визита
	•	специалиста

Ограничения
	•	link одноразовый
	•	link валиден 24 часа
	•	link привязан к user_id
	•	link привязан к visit_id

2️⃣ Формат magic link

Пример (структура, не строка):

https://trustwho.app/review/<token>
Где <token>:
	•	случайный
	•	хранится в БД
	•	содержит:
	•	user_id
	•	visit_id
	•	expires_at
	•	used_at (nullable)

⸻

3️⃣ Поведение при открытии ссылки

Если link валиден:
	1.	Пользователь автоматически авторизуется
	2.	Сразу открывается экран оставить отзыв
	3.	Без формы логина
	4.	Без лишних экранов

Если link:
	•	истёк
	•	уже использован
	•	невалиден

👉 показать экран:

Заголовок:

Ссылка больше не активна

Текст:

Вы можете оставить отзыв, войдя в приложение вручную

(без ошибок, без технических сообщений)

⸻

4️⃣ Поведение после оставления отзыва
	•	magic link помечается как used_at
	•	повторное открытие:
	•	либо редирект на карточку специалиста
	•	либо сообщение «Отзыв уже оставлен»

⸻

5️⃣ WhatsApp текст (жёстко зафиксировать)

Использовать один текст, без A/B:

👋 Спасибо за визит!

Оставьте отзыв о специалисте — это займёт меньше минуты:

👉 {{magic_link}}

Ваш отзыв поможет другим выбрать надёжного специалиста.

⚠️ Без упоминания регистрации, логина, аккаунта.

⸻

6️⃣ Метрики (сразу заложить)

Добавить логирование:
	•	magic_link_created_at
	•	magic_link_opened_at
	•	review_submitted_at

Чтобы можно было считать:
	•	открытие ссылки
	•	конверсию
	•	время до отзыва

⸻

7️⃣ Что НЕ делать

❌ Не использовать email
❌ Не показывать форму логина
❌ Не делать magic link постоянным
❌ Не усложнять UX

⸻

8️⃣ Критерии готовности (Definition of Done)
	•	После оплаты визита создаётся magic link
	•	Ссылка открывается без логина
	•	Пользователь сразу видит форму отзыва
	•	Повторное использование невозможно
	•	Истёкшая ссылка корректно обрабатывается
	•	Текст WhatsApp соответствует ТЗ
