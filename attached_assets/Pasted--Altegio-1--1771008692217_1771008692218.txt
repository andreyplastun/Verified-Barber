ТЗ: Экран ошибок интеграции Altegio

⸻

1. Цель

Дать специалисту понятное объяснение, почему интеграция с Altegio не работает, и что нужно сделать.

Экран должен:

✔ снижать панику
✔ объяснять проблему человеческим языком
✔ давать одно очевидное действие

⸻

2. Когда показывается экран

Экран отображается при любом критическом сбое Altegio:

1️⃣ Токен истёк
2️⃣ Доступ отозван в Altegio
3️⃣ Altegio API недоступен
4️⃣ Неверные ключи API
5️⃣ Company / Staff не найдены

⸻

3. Типы ошибок

⸻

A. Токен истёк

Условие:
Altegio API → 401 / unauthorized

UI:

Заголовок:

⚠️ Подключение к Altegio прервано

Текст:

Сессия Altegio истекла. Rateus больше не может обмениваться данными.

Подсказка:

Это нормально. Просто переподключите Altegio.

Кнопки:

✔ Переподключить Altegio (primary)
✔ Закрыть (secondary)

⸻

B. Доступ отозван

Условие:
Webhook / API → revoked / forbidden

UI:

Заголовок:

❌ Доступ к Altegio отозван

Текст:

В Altegio отключили приложение Rateus.

Подсказка:

Нужно заново разрешить доступ.

Кнопки:

✔ Подключить заново
✔ Закрыть

⸻

C. Altegio API недоступен

Условие:
Timeout / network / 5xx

UI:

Заголовок:

🌐 Altegio временно недоступен

Текст:

Не удалось связаться с Altegio.

Подсказка:

Попробуем снова автоматически.

Кнопки:

✔ Повторить сейчас
✔ Закрыть

⸻

D. Неверные API-ключи

Условие:
403 / invalid token / invalid credentials

UI:

Заголовок:

🔐 Ошибка авторизации Altegio

Текст:

Rateus не может войти в Altegio.

Подсказка:

Проверьте токены или переподключите интеграцию.

Кнопки:

✔ Переподключить Altegio

⸻

E. Staff / Company не найдены

Условие:
Altegio API → staff_id / company_id invalid

UI:

Заголовок:

👤 Специалист не найден в Altegio

Текст:

Rateus не может сопоставить мастера.

Подсказка:

Откройте настройки интеграции.

Кнопки:

✔ Настройки Altegio

⸻

4. Общая структура экрана

Иконка (по типу ошибки)
Заголовок
Описание
Подсказка
Primary кнопка
Secondary кнопка (Закрыть)

⸻

5. Поведение кнопок

⸻

Переподключить Altegio

→ переход в Altegio OAuth flow

⸻

Повторить сейчас

→ повторный API-запрос

⸻

Настройки Altegio

→ экран интеграции специалиста

⸻

6. Автологика

⸻

При временной ошибке (API down)

✔ retry в фоне:
	•	через 30 сек
	•	через 2 мин
	•	через 10 мин

✔ экран НЕ блокирует работу

⸻

При критической ошибке (401 / revoked)

✔ sync отключается
✔ показывается экран
✔ действия требуют пользователя

⸻

7. Индикация в UI визита

Если Altegio не работает:

Статус визита:

⚠️ Altegio: не синхронизировано

Tooltip:

Интеграция Altegio недоступна

⸻

8. Логирование

Логировать:

✔ тип ошибки
✔ specialist_id
✔ endpoint
✔ код ответа Altegio

⸻

9. Метрики

Собирать:

✔ количество 401
✔ количество revoked
✔ количество API timeout
✔ CTR кнопки “Переподключить”

⸻

10. UX-принципы

✔ без тех. терминов (401 / token invalid не показывать)
✔ не обвинять пользователя
✔ всегда давать действие
✔ не перегружать текстом

⸻
