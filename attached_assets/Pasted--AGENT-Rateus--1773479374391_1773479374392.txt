ЗАДАНИЕ ДЛЯ РАЗРАБОТЧИКА / AGENT  
Юридическое размещение документов на сайте Rateus

Цель: корректно разместить юридические документы (Privacy Policy, Terms of Service, Offer для специалистов) и обеспечить подтверждение согласия пользователей.

────────────────

1. СОЗДАТЬ СТРАНИЦЫ ДОКУМЕНТОВ

Создать отдельные страницы:

/privacy  
Политика конфиденциальности

/terms  
Пользовательское соглашение

/offer  
Оферта для специалистов

Страницы должны открываться без авторизации.

────────────────

2. FOOTER САЙТА

Добавить в нижнюю часть сайта (footer):

Политика конфиденциальности  
Пользовательское соглашение  
Оферта для специалистов

Ссылки должны быть доступны:

• на главной странице  
• на странице логина  
• на странице регистрации  
• на страницах профилей специалистов  
• в админке

Формат:

Политика конфиденциальности | Пользовательское соглашение | Оферта для специалистов

────────────────

3. ГАЛОЧКА ПРИ РЕГИСТРАЦИИ КЛИЕНТА

На странице регистрации клиента добавить обязательный чекбокс:

☐ Я принимаю условия Пользовательского соглашения и Политику конфиденциальности

Слова должны быть кликабельными ссылками:

Пользовательского соглашения → /terms  
Политику конфиденциальности → /privacy

Регистрация невозможна без установленной галочки.

Система должна сохранить:

• дату согласия  
• IP пользователя  
• версию документа

────────────────

4. ГАЛОЧКА ПРИ РЕГИСТРАЦИИ СПЕЦИАЛИСТА

На странице добавления специалиста или регистрации специалиста добавить чекбокс:

☐ Я принимаю Пользовательское соглашение, Политику конфиденциальности и Оферту для специалистов

Ссылки:

Пользовательское соглашение → /terms  
Политика конфиденциальности → /privacy  
Оферта для специалистов → /offer

Без галочки регистрация специалиста невозможна.

Сохранять:

• дату согласия  
• IP  
• версию документов

────────────────

5. ДОПОЛНИТЕЛЬНО ПРИ ОПЛАТЕ (В БУДУЩЕМ)

Если появится оплата:

Перед оплатой добавить текст:

Нажимая «Оплатить», вы соглашаетесь с Пользовательским соглашением и Офертой.

────────────────

6. ПОВТОРНОЕ СОГЛАСИЕ ПРИ ОБНОВЛЕНИИ

Если версия документов изменена:

При следующем входе пользователя показать модальное окно:

"Условия использования сервиса обновлены. Для продолжения необходимо принять новую редакцию."

Кнопка:

Принять

После нажатия сохраняется новая версия согласия.

────────────────

7. ПУБЛИЧНЫЙ ДОСТУП

Все документы должны быть доступны:

• без регистрации  
• без авторизации  
• через прямую ссылку

Это важно для юридической валидности.

────────────────

8. SEO И ИНДЕКСАЦИЯ

Разрешить индексирование страниц:

/privacy  
/terms  
/offer

Это стандарт для публичных юридических документов.

────────────────

9. MOBILE UX

На мобильной версии:

Footer должен отображать:

Политика конфиденциальности  
Пользовательское соглашение  
Оферта для специалистов

В виде вертикального списка.

────────────────

10. ЛОГИРОВАНИЕ СОГЛАСИЯ

В базе данных хранить:

user_id  
document_type (terms/privacy/offer)  
version  
timestamp  
ip_address

Это защита на случай юридических споров.
