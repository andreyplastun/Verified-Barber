Привести интерфейс trustwho.app в понятное, нейтральное, доверительное состояние, без визуального шума, без фиолетового «кричания», с ясным разделением:
	•	кто специалист
	•	почему ему можно доверять

⸻

1. БЛОК РЕЙТИНГА (КЛЮЧЕВОЕ)

Структура (ОБЯЗАТЕЛЬНО):

В правой колонке / по правому краю карточки:

⭐ 4.5
10 визитов
[ Сформированный рейтинг ⓘ ]
•	Всё выровнено по правому краю, НЕ по центру карточки
	•	Рейтинг не смешивается с описанием специалиста
	•	Tooltip (ⓘ):
«Рейтинг сформирован на основе достаточного количества подтверждённых визитов»

Уровни рейтинга (ТОЛЬКО 2, без третьего):
	1.	Рейтинг формируется
	•	текст:
«Рейтинг будет точнее по мере увеличения количества отзывов»
	•	порог: < 10 визитов
	2.	Сформированный рейтинг
	•	порог: ≥ 10 визитов
	•	больше никаких «высокая / низкая достоверность»

⸻

2. УБРАТЬ ВИЗУАЛЬНЫЙ ШУМ

Удалить/не показывать:
	•	«Рейтинг надёжный»
	•	«Рейтинг основан только на завершённых визитах»
	•	любые дубли пояснений рейтинга

Правило:
👉 один смысл = одна надпись

⸻

3. ОПИСАНИЕ СПЕЦИАЛИСТА (ВАЖНО)

Добавить:
	•	поле описания специалиста:
140–200 символов
	•	редактируется специалистом
	•	располагается ОТДЕЛЬНО от рейтинга, под именем и профессией

Пример:

«Специализируюсь на женских стрижках и окрашивании. Более 7 лет опыта, работаю с индивидуальным подбором образа.»

⸻

4. ЦВЕТА И СТИЛЬ (КРИТИЧНО)

Немедленно:
	•	УБРАТЬ фиолетовый из:
	•	формы логина
	•	ленты специалистов
	•	акцентных кнопок (кроме одного primary)

Использовать:
	•	светлый фон (белый / светло-серый)
	•	нейтральные акценты (серый / графит / чёрный)
	•	один спокойный primary-цвет (не фиолетовый)

⸻

5. ЛОГИН — БАГ (БЛОКЕР)

Исправить:
	•	форма логина НЕ должна уезжать вправо
	•	НЕ должна дёргаться / подвисать
	•	на мобильных:
	•	центрирование
	•	фиксация при открытии клавиатуры
	•	без horizontal scroll

⸻

6. ФИЛЬТРЫ (ДОБАВИТЬ)

Минимальный набор:
	•	по локации
	•	по рейтингу
	•	по количеству визитов

Сортировка по умолчанию:
	1.	Сформированный рейтинг
	2.	Ближе по локации
	3.	Выше рейтинг

Пустое состояние (ОБЯЗАТЕЛЬНО):

«В этом районе пока нет специалистов со сформированным рейтингом»

⸻

7. ПРОВЕРКА ПОСЛЕ ВЫПОЛНЕНИЯ

Агент должен показать:
	•	карточку специалиста:
	•	с описанием 140–200 символов
	•	с рейтингом справа
	•	экран логина без сдвигов
	•	список специалистов без фиолетового
	•	фильтры работают / видны

⸻

	•	Не добавлять новых терминов
