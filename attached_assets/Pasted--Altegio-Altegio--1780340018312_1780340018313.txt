ТЗ: исправить онбординг для специалистов без Altegio + корректно отображать подключённый Altegio

Сейчас часть специалистов регистрируется, указывает WhatsApp и ожидает, что отзывы начнут появляться автоматически. Они не понимают, что без Altegio нужно самостоятельно создавать визиты для запуска запроса отзыва.

Одновременно есть проблема с пользователями, у которых Altegio подключён: система уже знает про онлайн-запись, но интерфейс выглядит так, будто ничего не настроено.

1. Исправить сценарий для специалистов без Altegio

Проблема

Сейчас пользователь видит:

- фото добавлено
- цена добавлена
- WhatsApp добавлен
- профиль почти заполнен

После чего возникает ложное ожидание:

"Ну всё, теперь отзывы должны появляться."

Но механизм получения отзывов не объяснён.

Новый порядок задач

Для пользователей без Altegio:

Было:

✅ Фото
✅ Цена
✅ Способ записи
⬜ Получить первый отзыв

Должно стать:

✅ Фото
✅ Цена
✅ Способ записи
⬜ Добавить первого клиента
⬜ Получить первый отзыв

Новый информационный блок

Если:
- нет Altegio
- создано 0 визитов

Показывать сверху карточку:

Как получить первый отзыв

1. Добавьте клиента
2. После визита отправьте ему ссылку на отзыв
3. Клиент оставит отзыв
4. Отзыв появится в вашем профиле

Кнопка:

«Добавить первого клиента»

Блокировать пункт "Получить первый отзыв"

Пока createdVisits = 0

Пункт должен отображаться как:

🔒 Получить первый отзыв

Подпись:

«Сначала добавьте первого клиента»

После создания первого визита:

✅ Добавить первого клиента
⬜ Получить первый отзыв

Подпись:

«Ожидаем отзыв клиента»

2. Исправить отображение Altegio

Проблема

Сейчас у специалиста подключён Altegio, запись работает, но интерфейс показывает пустое поле:

"Ссылка на онлайн-запись"

Пользователь делает вывод:

"У меня ничего не настроено."

Если подключён Altegio:

- Не показывать пустое поле ссылки.
- Не показывать поле для ручного ввода ссылки.

Вместо этого отображать карточку:

✅ Онлайн-запись подключена

Источник: Altegio

Кнопка:

«Открыть ссылку записи»

Чек-лист

Сейчас:

⬜ Добавить способ записи

Должно автоматически становиться:

✅ Способ записи настроен

Источник: Altegio

Под статусом показать:

«Мы автоматически получили ссылку на онлайн-запись из Altegio. Клиенты смогут записываться через кнопку "Записаться".»

Добавить кнопку:

«Посмотреть как видят клиенты»

Открывает публичный профиль специалиста.

3. Изменить объяснение механики получения отзывов

Убрать формулировки, создающие ощущение автоматического появления отзывов.

Вместо абстрактного:

«Получите первый отзыв»

Использовать цепочку:

Добавьте клиента → отправьте ссылку → получите первый отзыв

Пользователь должен понимать, что отзыв появляется только после создания визита, а не после регистрации аккаунта.

Цель

После регистрации любой специалист за несколько секунд должен понимать:

Если подключён Altegio:
- запись уже работает автоматически
- ничего дополнительно настраивать не нужно
- осталось получить первые отзывы

Если Altegio не подключён:
- нужно добавить клиента вручную
- после визита отправить ссылку
- только после этого появится первый отзыв

Сейчас эта разница пользователю неочевидна и вызывает путаницу.
