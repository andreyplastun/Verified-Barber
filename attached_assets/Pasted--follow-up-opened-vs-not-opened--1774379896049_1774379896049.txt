2. СЕГМЕНТАЦИЯ

Для каждого booking:

A. NOT_OPENED:
- link_opened_at IS NULL
- review отсутствует

B. OPENED_NOT_CONVERTED:
- link_opened_at есть
- review отсутствует

C. CONVERTED:
- есть review

scheduled_at = link_opened_at + random(2–4 часа)
priority = HIGH

---

B. Если NOT_OPENED:

scheduled_at = primary_sent_at + random(18–24 часа)

C. Если есть review:
