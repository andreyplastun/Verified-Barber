3. ДОБОР ДО ЛИМИТА (ГЛАВНОЕ)

Сейчас:
- берётся LIMIT available → часть не отправляется → итог < лимита

Нужно:
- добавить цикл добора

Псевдокод:

let sent = 0

while (sent < daily_limit) {
  const candidates = select из wa_messages
    where status = 'queued'
      and scheduled_at <= now
    limit (daily_limit - sent) * 3

  if (candidates.length === 0) break

  for (msg of candidates) {
    if (sent >= daily_limit) break

    const ok = processOneMessage(msg)

    if (ok) sent++
  }

  если ни одно сообщение не отправилось → break (защита от бесконечного цикла)
}
