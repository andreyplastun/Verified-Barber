ТЗ дизайнеру (Figma)

Блок: Статус интеграции Altegio в кабинете специалиста

⸻

🎯 Цель блока

Показать специалисту состояние интеграции Altegio:

✔ понятно
✔ без технарщины
✔ без тревожных “ERROR / FAILED”

Блок = элемент контроля, не алерт.

⸻

📍 Расположение

Экран: Кабинет специалиста → Профиль

Позиция:
Под именем и ролью специалиста
или
В секции “Интеграции”

(приоритет: под профилем, выше настроек)

⸻

📐 Размеры и отступы

Контейнер:

• ширина: 100% доступной области
• высота: auto
• padding: 12–14 px
• border-radius: 12 px

Отступы:

• сверху: 12 px
• между иконкой и текстом: 8 px
• между строками текста: 2–4 px

⸻

🎨 Визуальный стиль

• фон: светлый (card style)
• рамка: тонкая / subtle (1 px, neutral)
• без тяжёлых плашек

Иконка слева:

• размер: 18–20 px
• стиль: outline / минимализм

⸻

🔤 Типографика

Строка 1 (заголовок):

• размер: 14–15 px
• вес: medium / semibold

Строка 2 (подпись):

• размер: 12–13 px
• вес: regular
• цвет: secondary / muted

⸻

✅ STATES (обязательные)

⸻

🟢 1. Подключено

Иконка: зелёный индикатор / link / check

Текст:

Altegio подключён

Подпись:

Синхронизация записей активна

Кнопок нет

⸻

🟡 2. Требует внимания

Иконка: warning / neutral yellow

Текст:

Altegio требует внимания

Подпись:

Нужно переподключить интеграцию

Кнопка справа:

[ Переподключить ]

Кнопка:

• высота: 28–32 px
• стиль: secondary / outline

Tooltip ⓘ рядом с текстом:

Интеграция временно недоступна.
Записи можно создавать вручную.

⸻

🔴 3. Не подключён

Иконка: neutral / grey link-off

Текст:

Altegio не подключён

Подпись:

Записи не синхронизируются

Кнопка:

[ Подключить ]

⸻

⚪ 4. Проверка / retry

Иконка: spinner / subtle

Текст:

Проверяем соединение…

Подпись отсутствует

Кнопок нет

⸻

🔘 Кнопки

Стиль:

• компактные
• без агрессивных цветов
• без primary CTA dominance

Текст кнопок:

✔ Подключить
✔ Переподключить

⸻

🚫 НЕЛЬЗЯ

❌ ERROR / FAILED / WARNING CAPS
❌ технические формулировки
❌ коды ошибок
❌ красные алерты на весь экран

⸻

💡 Поведение

• блок статичный
• без тряски / мигания
• смена state → мягкий fade

Анимация:

opacity 150–200 ms

⸻

📱 Мобильная адаптация

✔ не более 2 строк текста
✔ кнопка не ломает сетку
✔ переносов типа “Altegio
подключён” избегать

⸻

✅ Результат

Специалист за 1 секунду понимает:

✔ синкается / не синкается
✔ нужно действие / не нужно
✔ без стресса

⸻

Если нужно, следующим шагом могу сделать:

🎨 ТЗ на цветовую систему состояний (точные HEX / opacity / иконки)
чтобы дизайнер и агент не импровизировали.
