ЗАДАЧА ДЛЯ АГЕНТА — Реализовать оплату Kaspi без Apipay

Цель:
Кнопка "Запросить оплату" должна отправлять клиенту ссылку Kaspi на оплату услуги.
После оплаты мастер вручную подтверждает оплату.
Только после этого визит завершается и отправляется magic link для отзыва.
Система не проверяет оплату автоматически.

--------------------------------------------------------------------

1. ИЗМЕНИТЬ ЛОГИКУ КНОПКИ "Запросить оплату"

Сейчас:
request-payment → payment_pending → completed → magic link → WhatsApp

Нужно:
request-payment → отправляется Kaspi ссылка → статус = payment_requested → ждём → мастер нажимает "Оплачено" → визит завершён → magic link

--------------------------------------------------------------------

2. ДОБАВИТЬ ПОЛЯ В BOOKING

price: number
paymentStatus: "none" | "requested" | "paid"

По умолчанию:
paymentStatus = "none"

--------------------------------------------------------------------

3. ФУНКЦИЯ ГЕНЕРАЦИИ KASPI ССЫЛКИ

function generateKaspiLink(phone, amount) {
  const cleanPhone = phone.replace(/\D/g, '')
  return `https://kaspi.kz/pay/P2P?phone=${cleanPhone}&amount=${amount}`
}

phone = specialist.kaspiPhone
amount = booking.price

--------------------------------------------------------------------

4. ENDPOINT ЗАПРОСА ОПЛАТЫ

POST /api/bookings/:id/request-payment

Логика:

1 получить booking
2 получить specialist
3 взять specialist.kaspiPhone
4 взять booking.price
5 создать kaspiLink
6 отправить WhatsApp клиенту
7 booking.paymentStatus = "requested"
8 booking.status = "payment_requested"

Визит НЕ завершать.

--------------------------------------------------------------------

5. ТЕКСТ WHATSAPP

Спасибо за визит!

Оплатить услугу можно через Kaspi:

{kaspiLink}

После оплаты мастер завершит визит и отправит ссылку для отзыва.

--------------------------------------------------------------------

6. ДОБАВИТЬ КНОПКУ "Отметить оплату"

В интерфейсе специалиста:

Кнопка: "Отметить оплату"

Endpoint:
POST /api/bookings/:id/mark-paid

--------------------------------------------------------------------

7. ЛОГИКА MARK PAID

booking.paymentStatus = "paid"
booking.status = "completed"

createMagicLink()

sendWhatsApp:

Спасибо за визит!

Будем благодарны за отзыв:

{magicLink}

--------------------------------------------------------------------

8. СТАТУСЫ ВИЗИТА

ready_to_complete
payment_requested
completed

Flow:

ready_to_complete
→ request-payment
→ payment_requested
→ mark-paid
→ completed

--------------------------------------------------------------------

9. ВАЛИДАЦИЯ

request-payment нельзя выполнить если:

нет booking.price
или нет specialist.kaspiPhone

--------------------------------------------------------------------

10. UI

Если paymentStatus = requested
→ показывать кнопку "Отметить оплату"

Если paymentStatus = paid
→ показывать "Визит завершён"

--------------------------------------------------------------------

ИТОГОВЫЙ FLOW

визит
→ мастер нажимает "Запросить оплату"
→ клиент получает Kaspi ссылку
→ клиент платит
→ мастер нажимает "Оплачено"
→ визит завершён
→ отправляется magic link
→ клиент оставляет отзыв
