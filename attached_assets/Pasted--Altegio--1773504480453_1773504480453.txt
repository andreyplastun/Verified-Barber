ЗАДАНИЕ АГЕНТУ

Название: Подтверждение оплаты для визитов без Altegio (ручная запись мастером)

Цель  
Исправить UX оплаты для визитов, которые создаются внутри Rateus вручную мастером (без интеграции с Altegio).  
В этих визитах используется Kaspi P2P ссылка, поэтому система не получает автоматического подтверждения платежа.  
Барбер должен вручную подтвердить получение денег.

Важно: это изменение НЕ должно затрагивать визиты из Altegio.

────────────────

1. ОБЛАСТЬ ПРИМЕНЕНИЯ

Изменения применяются только к визитам без Altegio.

Условие:

visit.source = rateus  
или  
visit.altegio_id = null

Для визитов:

visit.source = altegio

логика не меняется вообще, потому что там завершение визита приходит из Altegio.

────────────────

2. ИЗМЕНИТЬ ТЕКСТ КНОПКИ

Для визитов без Altegio заменить кнопку:

"Отметить оплату"

на

"Подтвердить оплату"

Кнопка показывается только если:

visit.status = payment_requested

────────────────

3. ДОБАВИТЬ CONFIRMATION DIALOG

При нажатии "Подтвердить оплату" показывать диалог:

Текст:

"Подтвердить получение оплаты {price} ₸?"

Кнопки:

Отмена  
Подтвердить

Если нажато "Подтвердить" — выполняется действие из пункта 4.

────────────────

4. ЛОГИКА ДЕЙСТВИЯ

После подтверждения оплаты система должна:

1. установить

booking.status = completed

2. сохранить

completed_at = now()

3. сгенерировать magic link для отзыва

4. отправить клиенту WhatsApp сообщение с magic link

Использовать существующую логику отправки review request.

────────────────

5. UI КАРТОЧКИ ВИЗИТА

Если статус:

payment_requested

показывать:

Запрос оплаты: {price} ₸  
Отправлен: {timestamp}

Кнопки:

Подтвердить оплату  
Повторить отправку

Кнопка "Повторить отправку" продолжает отправлять Kaspi P2P ссылку.

────────────────

6. НЕ ТРОГАТЬ ВИЗИТЫ ALTEGIO

Для визитов:

visit.source = altegio

НЕ менять:

• статусную модель  
• завершение визита  
• отправку отзывов  
• логику оплаты

Эти визиты завершаются через webhook Altegio.

────────────────

7. НЕ МЕНЯТЬ СУЩЕСТВУЮЩИЕ МЕХАНИЗМЫ

Не менять:

• scheduler WhatsApp  
• throttling  
• quiet hours  
• follow-up logic  
• resend payment request  
• генерацию Kaspi P2P ссылки

Изменяется только UX подтверждения оплаты.

────────────────

8. ОЖИДАЕМЫЙ FLOW (ВИЗИТ БЕЗ ALTEGIO)

Мастер создаёт визит вручную  
↓  
После услуги нажимает "Запросить оплату"  
↓  
Клиент получает Kaspi P2P ссылку  
↓  
Клиент переводит деньги  
↓  
Мастер нажимает "Подтвердить оплату"  
↓  
Визит получает статус completed  
↓  
Клиенту отправляется magic link для отзыва

────────────────

РЕЗУЛЬТАТ

Для визитов без Altegio барбер вручную подтверждает получение денег, визит завершается и клиент получает ссылку на отзыв.  
Визиты из Altegio продолжают работать по текущей интеграционной логике.
